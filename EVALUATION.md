# Evaluation metrics and experiments

Temporal generalization holds later timestamps for validation/test; rolling-origin folds train only on earlier times. Spatial generalization holds out grid IDs; GroupKFold is available for grouped folds. These experiments answer different questions and must be reported separately. The orchestration currently performs temporal holdout; spatial split APIs are provided.

Classification threshold is selected on validation using the configured objective (F1 by default; accuracy is available), and the test window is used only for final scores. Classification: accuracy is total correct fraction; precision is rain forecasts that occurred; recall/POD is observed rain detected; F1 balances precision and recall; ROC-AUC measures ranking across thresholds; PR-AUC emphasizes rare positives; confusion matrix reports TN/FP/FN/TP; FAR is false alarms among rain forecasts; CSI is hits over hits plus misses and false alarms; ETS adjusts CSI for random hits. Regression: MAE is average absolute error; RMSE penalizes large errors more; R² measures variance explained; bias is mean prediction minus observation; correlation measures linear association. XGBoost feature permutation importance is computed on validation only. No single metric establishes a universally best rainfall model.
